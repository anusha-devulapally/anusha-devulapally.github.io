PhD candidate in Computer Science and Engineering at Penn State, advised by Prof. Vijaykrishnan Narayanan. Graduating January 2027. Open to full-time roles starting 2027.

I build AI systems that spend compute and memory only where it matters.

AI now runs on robots, vehicles and edge devices that read several sensors at once, while models and datasets outgrow the memory of a single GPU. Moving data has become more expensive than computing on it. Yet most systems still process every sensor on every frame, and add memory tiers without knowing when they will pay off. My research makes AI execution workload-aware, from which sensor a model reads on each frame down to which memory tier its data lives in.

Publications at MICRO, ISPASS, MEMSYS, CVPR Workshops, ACM Multimedia, VLSI Design and NeurIPS Workshops, seven as first author. Internships at SK hynix America and Pacific Northwest National Laboratory.

Research

Adaptive multimodal perception

Robots and vehicles carry several sensors, but fusing all of them on every frame costs latency and energy even when one adds little.

Depth from RGB and event cameras, with a gate that decides

Pairs a frozen depth foundation model with an event transformer. A lightweight gate chooses RGB-only, event-only or fused inference for each input, so the event branch runs when it helps most: low light, motion blur and sparse frames. Evaluated on MVSEC and DSEC.

Accuracy within 1% of always-on fusion, with about 8% lower latency by day, 12% at night, and 22% less GPU energy in RGB-only mode.

In submission, 2026

One transformer for events and RGB

A unified transformer that fuses event and RGB data for monocular depth estimation. Events pass through ConvLSTM blocks to keep their timing, then both modalities share one transformer encoder instead of running two.

Nearly half the runtime memory of prior fusion work (340 MB vs. 652 MB).

Memory-centric systems

Models and datasets now outgrow a single GPU, and new memory tiers such as CXL are added for capacity without a principled way to predict when they pay off.

Modeling data movement across memory tiers

Extends the classic red-blue pebble game with a shared memory-pool tier between fast local memory and slow storage, and weights each move by its cost. Schedules for workloads such as FFT and ResNet can then be compared by how much data they move.

Up to 3x lower modeled I/O cost for deep networks.

When does disaggregated memory pay off?

Proposes isoefficiency, a classic HPC scalability metric, as a way to judge how well a workload scales on CXL-based disaggregated memory. Evaluated with sparse matrix multiplication on a two-socket server and a simulated CXL memory system.

MEMSYS 2024, first author

Paper

Processing in and near CXL memory

Co-authored work that moves computation closer to CXL memory: processing inside the CXL fabric switch for large-scale recommendation inference (PIFS-Rec), a general-purpose tiered process-near-memory framework (TPNM), and ML-pipeline optimization in cost-effective disaggregated datacenters.

PIFS-Rec: 3.89x lower latency than Pond, an industry-standard CXL system, and 2.03x better than BEACON.

AI for chip design

As processors split into chiplets on one package, designers need temperature estimates far faster than full thermal simulation allows.

Transformer thermal surrogates for 2.5D chiplets

ThermLeT predicts the temperatures of 2.5D chiplet systems with a transformer instead of slow thermal simulation. PhysThermix builds on it with thermal-conductivity and heat-transfer maps, plus physics losses from the heat equation and boundary conditions.

5.9x faster than prior methods.

VLSI Design 2026 (ThermLeT, co-first author), NeurIPS 2026 Workshop on AI for Chip Design (PhysThermix)
