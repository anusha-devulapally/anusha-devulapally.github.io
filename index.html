I build AI systems that spend compute and memory only where it matters.

AI now runs on robots, vehicles and edge devices that read several sensors at once, while models and datasets outgrow the memory of a single GPU. Moving data has become more expensive than computing on it. Yet most systems still process every sensor on every frame, and add memory tiers without knowing when they will pay off. My research makes AI execution workload-aware, from which sensor a model reads on each frame down to which memory tier its data lives in.

15 publications, 7 as first author, at MICRO, ISPASS, MEMSYS, CVPR Workshops, ACM Multimedia, NeurIPS Workshops and VLSI Design. Internships at SK hynix America and Pacific Northwest National Laboratory.

Research

Adaptive multimodal perception

Robots and vehicles carry several sensors, but fusing all of them on every frame costs latency and energy even when one adds little.

Depth from RGB and event cameras, with a gate that decides

Pairs a frozen depth foundation model with an event transformer. A lightweight gate chooses RGB-only, event-only or fused inference for each input, so the event branch runs when it helps most: low light, motion blur and sparse frames. Evaluated on MVSEC and DSEC.

Accuracy within 1% of always-on fusion, with about 8% lower latency by day, 12% at night, and 22% less GPU energy in RGB-only mode.

In submission, 2026

One transformer for events and RGB

A unified transformer-based architecture with a shared encoder that fuses event and RGB data for monocular depth estimation.

Nearly half the runtime memory of prior fusion work (340 MB vs. 652 MB).

CVPR Workshops 2024, first author

Memory-centric systems

Models and datasets now outgrow a single GPU, and new memory tiers such as CXL are added for capacity without a principled way to predict when they pay off.

Modeling data movement across memory tiers

Adds a pooled-memory tier to the classic red-blue pebble game and weights each move by its real cost, so schedules for deep networks can be compared by how much data they move.

Up to 3x lower modeled I/O cost for deep networks.

MEMSYS 2025, first author

When does disaggregated memory pay off?

Uses isoefficiency, a classic HPC scalability metric, to judge how far a workload can scale on disaggregated memory before efficiency drops.

MEMSYS 2024, first author

Processing in and near memory

Co-authored work on computing inside the CXL fabric switch for large-scale recommendation inference, tiered processing near memory, and auto-tuning ML pipelines on NUMA and CXL memory.

MICRO 2024, ISPASS 2025, MICRO 2025

AI for chip design

As processors split into chiplets on one package, designers need temperature estimates far faster than full thermal simulation allows.

Transformer thermal surrogates for 2.5D chiplets

Transformer models that predict chiplet temperatures in place of slow simulation. PhysThermix adds thermal-conductivity and heat-transfer maps, plus physics losses from the heat equation and boundary conditions.

5.9x faster than prior methods.
